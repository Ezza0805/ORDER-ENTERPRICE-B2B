# Order Enterprise B2B

Project vanilla HTML/CSS/JavaScript hasil pemisahan dari file HTML tunggal.

## Struktur

- `index.html` — struktur halaman
- `css/style.css` — seluruh CSS inline
- `js/app.js` — seluruh JavaScript
- `package.json` — script development server

## Menjalankan

```bash
npm install
npm run dev
```

Kemudian buka:

`http://localhost:3000`
